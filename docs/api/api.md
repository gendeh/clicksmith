# Clicksmith API (MVP)

## Auth
- `POST /api/v1/auth/signup`
- `POST /api/v1/auth/login`

## Profiles
- `GET /api/v1/profiles`
- `POST /api/v1/profiles`
- `PUT /api/v1/profiles/:id`
- `DELETE /api/v1/profiles/:id`

## Image Matching
- `POST /api/v1/image/match`

## Billing
- `POST /api/v1/billing/checkout`
- `POST /api/v1/billing/webhook`
