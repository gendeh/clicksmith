# Clicksmith Pitch Deck (Outline)

1. **Title**: Clicksmith - Safe, human-in-the-loop input automation
2. **Problem**: Repetitive UI workflows cost time; existing tools are brittle or unsafe.
3. **Solution**: Overlay-based recording + SmartClick replay with Takeover control.
4. **Why Now**: Explosion of automation needs in QA, creators, and solo workflows.
5. **Product**: Demo flow: Record -> Play -> Takeover -> Save/Discard.
6. **Safety**: No injection, no memory reads, strict EULA.
7. **Market**: Desktop automation + QA tooling; initial wedge in single-player games and local apps.
8. **Business Model**: Freemium + Pro subscriptions.
9. **Roadmap**: Auto-tune, cloud sync, adaptive timing inference service.
10. **Ask**: Funding for native hook hardening + enterprise integrations.
