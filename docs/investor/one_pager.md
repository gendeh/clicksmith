# Clicksmith Investor One-Pager

## Vision
Clicksmith enables safe, human-in-the-loop input automation for single-player and local workflows, with guardrails that avoid memory injection and online competitive misuse.

## Problem
Power users and QA teams waste hours repeating deterministic sequences across desktop apps and games. Existing macro tools are brittle, unsafe, or violate platform rules.

## Solution
Clicksmith records precise input with contextual screenshots, replays reliably via SmartClick image matching, and lets humans take over mid-run to correct or guide outcomes.

## Differentiation
- Overlay-first UX with immediate Takeover control
- SmartClick visual matching vs. brittle coordinates
- Safety-first compliance (no injection/memory reads)
- Built-in Save/Discard run gating to protect quality

## Business Model
Freemium: Free tier (local profiles, 3 saved profiles). Pro ($4.99/mo or $39/yr) unlocks unlimited profiles, cloud sync, auto-tune, and priority support.

## Go-To-Market
Initial focus on hobby automation and QA teams for internal tooling. Expand via content creators and automation communities with strict compliance messaging.

## Roadmap
Auto-tune timing optimization, cross-device cloud profiles, and optional inference service for adaptive timing.
