# Release Notes

## Clicksmith MVP 0.1.0

- Overlay-based recording/playback with Takeover hotkey.
- Save/Discard run flow with profile versioning.
- SmartClick image matching with retries and confidence thresholds.
- Electron client packaged for Windows with NSIS installer.
- Flask image-service with template + feature matching and OCR.
- Firebase/Stripe backend scaffolding with mock fallback.
